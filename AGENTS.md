# AirGapper

Build a simple, fully offline screen-to-camera file and text transfer tool, primarily for an older Android receiver with no network connection.

- Keep maintainable TypeScript source and the minimal build pipeline needed to produce the self-contained root `index.html`.
- Do not add or run tests or verification. Do not add prose documentation.
- Optimize for fast iteration: make minimal, direct code changes and rebuild only when `index.html` must change.
- After changes, commit and push.
